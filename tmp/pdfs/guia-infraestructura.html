PARA USO GENERAL

La infraestructura en pocas palabras

Es el conjunto de piezas que permite que una aplicación reciba solicitudes, guarde información, procese tareas y muestre con claridad si todo está funcionando.

Una puerta de entrada

Traefik recibe las solicitudes, valida las rutas protegidas y dirige cada petición al servicio correcto.

Dos servicios

FastAPI y Fastify permiten validar que componentes en lenguajes distintos trabajen de forma coordinada.

Memoria y datos

PostgreSQL conserva la información y Redis acelera consultas frecuentes con cache-aside.

Trabajo en segundo plano

RabbitMQ transporta eventos entre servicios para desacoplar la petición del procesamiento.

Cómo viaja una solicitud

Persona o sistema -> puerta de entrada -> JWT y rol validados -> servicio adecuado -> datos o mensaje -> respuesta. El entorno registra cada paso para facilitar la operación.

Seguridad actual

Las rutas protegidas se validan directamente en Traefik mediante JWT firmados con HMAC. No se despliega un proveedor de identidad; los tokens de desarrollo se generan localmente.

Arquitectura y flujos

Un único proyecto Docker Compose organiza los componentes en la red interna demo-observability-net. Los microservicios no exponen puertos al host.

Reglas de exposición

Solo Traefik publica la API en :8000. PostgreSQL, Redis y RabbitMQ publican sus puertos en localhost para desarrollo; los servicios de aplicación permanecen internos. Las rutas protegidas usan JWT locales firmados con HMAC.

OPERACIÓN

Observar, diagnosticar, actuar

La observabilidad permite pasar de una alerta general a la causa concreta sin adivinar.

Métricas
Prometheus

¿Cuánto tráfico, error o latencia hay?

Trazas
OpenTelemetry -> Tempo

¿En qué paso se demoró o falló la solicitud?

Logs
OpenTelemetry -> Loki

¿Qué detalle explica el evento?

Grafana: una vista unificada

Grafana conecta Prometheus, Loki y Tempo. El identificador trace_id une una respuesta, su traza y sus logs: primero se detecta el problema en métricas, luego se ubica en la traza y por último se explica con registros.

Límites actuales y siguiente paso

Es un entorno de demostración y desarrollo: Traefik valida JWT de prueba generados localmente, el dashboard usa configuración insegura, no hay TLS y los secretos parten de valores de ejemplo. Para producción se requieren gestión de secretos, TLS, control de acceso al dashboard, imágenes inmutables y alta disponibilidad.
